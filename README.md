# ソフトテニス ダブルス・テリトリー可視化アプリ

React + TypeScript + Viteで作ったプロトタイプです。

## 起動方法

```bash
npm install
npm run dev
```

表示されたURLをブラウザで開きます。通常は次のURLです。

```text
http://localhost:5173/
```

## 使い方

- A/B/C/Dの丸アイコンをドラッグして選手位置を動かせます。
- 選手はコート内だけでなく、コート外にも動かせます。
- 初期状態ではDを打球者Hとして扱います。操作パネルでC/Dを切り替えられます。
- 薄いオレンジは、Hからこちら側コートへ返球される可能性のある角度範囲です。
- 死角は表示しませんが、Hの前後位置から有効返球幅を計算し、極端なサイド方向は返球可能範囲から除外します。
- 黄色は前衛Bのテリトリー、青色は後衛Aのテリトリーです。
- AやBを動かしても、黄色と青色のテリトリー形状は変わりません。
- 「前衛Bの担当サイド」で、黄色を右側にするか左側にするかを切り替えられます。
- 返球範囲の広さは `spreadMultiplier = 1.25` 固定です。
- Dをネットに近づけると有効返球幅が広がり、後ろに下げると狭くなります。
- 「初期配置に戻す」ボタンで最初の配置に戻せます。
